# AI Cheat Sheets: Developer

Short, practical guides for the AI tools that matter most for your day-to-day work as a
developer. These are not required reading before the workshop, but if you have little or no
experience with AI tools, start here rather than jumping straight into the exercises.

If you already use these tools regularly, skim them anyway: there may be a feature or shortcut
you haven't tried.

## What's here

- [`github-copilot.md`](github-copilot.md): the core tool for the entire day. Start here if you
  read nothing else.
- [`copilot-in-your-ide.md`](copilot-in-your-ide.md): where to find Copilot's features in
  IntelliJ, Visual Studio, and VS Code specifically.
- [`claude-code-cli.md`](claude-code-cli.md): a terminal-based alternative to Copilot, useful if
  you have access to it.
- [`what-is-mcp.md`](what-is-mcp.md): what the "hosted MCP server" you'll connect to in Block 3
  actually is and why it matters.

If something breaks and these guides don't cover it, see `../../ai-tooling-fallback.md` or ask
your coach.
